# Dr.life+ UI 标准 v1（官网 + Mini App）

2026-11-12 定。**基准是老板提供的官网首页 v2**（`design/website/homepage-v2/`），以它的配色、字体、版式为准；结构、高棉语、可访问性和 Mini App 规则沿用 Design 方案 A（ai-shared-memory #30 / PR #31，黑金统一）。D-01 结论：**官网与 Mini App 统一黑金 VI（方案 A）**，Mini App 不再用商城绿。

变量全部在 [`tokens.css`](./tokens.css)，组件只引用语义变量（`--bg`、`--text`、`--accent-*` 等），不写死色值和字号。本标准取代 `design/website/typography.md`。

## 1. 原则
1. **一套 VI**：深色（#171817）+ 米色（#f6f2e9）+ 香槟金（#d6b97e）+ 铜色字（#80612e）。直角、细线分隔、实景大图。
2. **同级一致**：同一级标题全站同一个变量；内页主标题和首页区块标题同级（`--fs-h1` = `--fs-h2`），只有首页首屏用 `--fs-display`。
3. **对齐一条线**：背景可以通栏，内容一律放在 `.container`（最大 1260px，左右留白 `--gutter`）里，左右边缘全站对齐。
4. **少换行**：能一行放下的标签、按钮、导航不换行（`white-space: nowrap`）；标题按语义断行（`<br>` 或分 span），不靠缩字号。

## 2. 布局
| 项 | 值 |
| --- | --- |
| 内容最大宽 | `--container: 1260px`，写法 `width: min(100% - 2*var(--gutter), var(--container)); margin-inline: auto` |
| 左右留白 | `--gutter: clamp(20px, 5.6vw, 90px)`（Mini App 固定 16px） |
| 区块上下留白 | `--section-y: clamp(60px, 8vw, 122px)` |
| 断点 | 760px（导航收起成菜单、多列变单列）、1024px（4 列变 2 列） |
| 栅格 | 版块卡片 2 列；合作入口 3 列；步骤、数据 4 列；760px 以下全部 1–2 列 |
| 左文右图 | `grid-template-columns: 1.08fr 1fr; gap: var(--split-gap)` |
| 标题 + 说明 | `1.2fr .75fr`，底部对齐（`.split-intro`） |
| 段落行宽 | 不超过 `--measure: 62ch` |
| 页头 | 高 76px（手机 64px），深色，吸顶；锚点跳转留 `scroll-padding-top` |

区块底色交替：米色 → 沙色 → 深色，相邻两个区块不用同一底色。

## 3. 字号与字体
| 级别 | 变量 | 手机 → 桌面 | 字体 / 字重 | 行高 / 字距 | 用在 |
| --- | --- | --- | --- | --- | --- |
| 首屏大标题 | `--fs-display` | 54 → 112px | 衬线 700 | 1.01 / -0.055em | 只用于首页首屏 h1 |
| 页面主标题 | `--fs-h1` | 32 → 54px | 衬线 700 | 1.32 / -0.028em | 内页 h1（商家页、法律页、联系页） |
| 区块标题 | `--fs-h2` | 30 → 54px | 衬线 700 | 1.32 / -0.028em | 每个区块的 h2 |
| 版块标题 | `--fs-h3` | 24 → 36px | 衬线 700 | 1.3 | 四大版块、建材城等大卡片 |
| 小标题 | `--fs-h4` | 15 → 19px | 无衬线 700 | 1.4 | 合作卡片、步骤、价值观 |
| 宣言 | `--fs-quote` | 21 → 35px | 衬线 700（英文 Georgia 斜体 400） | 1.58 | 集团文化 |
| 导语 | `--fs-lead` | 16 → 22px | 无衬线 650 | 1.5 | 首屏定位句、版块副标题 |
| 英文副标题 | `--fs-tagline` | 12 → 17px | system-ui 600 | 0.24em（手机 0.16em） | INFINITE POSSIBILITIES |
| 正文 | `--fs-body` | 14 → 16px | 无衬线 400 | 1.8 | 段落 |
| 小字 | `--fs-small` | 13px | 无衬线 400 | 1.55 | 列表、说明、页脚 |
| 标签 | `--fs-caption` | 12px | 无衬线 700，大写 | 0.17em | eyebrow、图片说明、pill |
| 数字 | `--fs-stat` | 34 → 44px | 衬线 400，金色 | 1.1 | 步骤编号 01–04 |

- **任何文字不小于 12px，高棉语不小于 13px**。（相对首页 v2 原稿的修正：eyebrow 11→12px、图片说明 10→12px、页脚版权 11→12px。）
- 高棉语：全部用 Noto Sans Khmer，不用衬线，不加字距，正文行高 1.85、标题行高 1.35。
- 英文：标题沿用衬线体的拉丁字形；英文宣言用 Georgia 斜体。
- 字体自托管 woff2，按页面实际用字做子集，`font-display: swap`。

## 4. 颜色
见 `tokens.css` 注释里的对比度（WCAG 2.2，全部 ≥ 4.5:1，边框 ≥ 3:1）。用法规则：
- **金色 #d6b97e 只用在深色底上的文字，或作主按钮底色**（浅底上当文字只有 1.69:1，禁止）。浅底上的强调字、链接、eyebrow 用铜色 #80612e。
- 分隔线 #d8d0c1、卡片描边 #cfc2ab 只做装饰；输入框和次按钮的描边用 `--color-border-strong`。
- 功能色（成功 / 警告 / 危险 / 信息）只用于状态，不当装饰色；深色模式用另一组（见 tokens）。

## 5. 组件
| 组件 | 规格 |
| --- | --- |
| 主按钮 | 金底深字；高 48px、左右 18px、14px 650；直角；悬停加深为 #c9a964；图标 `↗` 或 `↓` 在文字后，间距 20px |
| 次按钮 | 透明底 + 1px 描边（深底用 #ffffff55，浅底用 `--color-border-strong`），其余同主按钮 |
| 文字链接 | 铜色 14px 700，底部 1px 线（#ad8955），后接 `↗` |
| 版块卡片 | 上图下文；图片 16:9，左下角深色半透明说明标签（12px）；正文区内边距 `clamp(18px,2.5vw,35px)`；白底 `--surface`，描边 `--color-border` |
| 信息列表 | 两列（标签 minmax(112px,.47fr) / 说明 1fr），行间 1px 顶线，13px |
| 标签 pill | 12px，内边距 4px 10px，描边 #cfc2ab，底 #f6f0e5 |
| 步骤 | 4 列，顶线金色、列间细竖线；编号用 `--fs-stat` 金色衬线 |
| 合作卡片 | eyebrow（12px 大写铜色）+ 小标题 + 说明 + 要点列表 + 文字链接 |
| 弹窗 | 纸色底、1px #c7b385 描边、阴影 `--shadow-dialog`、最大宽 580px |
| 表单 | 高 44px、1px `--color-border-strong`、纸色底、聚焦时铜色描边；错误文字用 `--color-danger` 并写明原因 |
| 表格（后台 / Mini App） | 表头 13px 700 沙色底；行高 ≥ 44px；数字右对齐、金额用整分格式 |
| 焦点 | 所有可点元素 `:focus-visible` 显示 2px 铜色（深底金色）外框，偏移 3px |
| 动效 | 只做颜色和透明度过渡 .18s；尊重 `prefers-reduced-motion` |

可点区域不小于 44×44px。

## 6. 图片
- 实景、暖色、夜景为主；每张图都要有三语 alt；示意图左下角标“场景示意 / 概念示意”。
- 导出 AVIF + WebP，640 / 1280 两档，单张 < 200KB；首屏图 `fetchpriority="high"`，其余懒加载。
- 未上线的二维码、链接不放演示版到线上，用“即将上线”。

## 7. Mini App（Telegram 内，360–430px）
- 加 `data-surface="miniapp"`：圆角 8px（底部弹层 16px）、左右 16px、标题档位缩到 22 / 18 / 16px、正文 15px。
- 亮色主题：米色底、纸色卡片、深色顶栏、金色主按钮（深字）。暗色主题（Telegram `colorScheme === "dark"`）：用 `[data-color-scheme="dark"]` 那一组，背景 #111210，功能色换亮色版。
- 不直接用 Telegram 的 `themeParams` 颜色当品牌色；只用它判断亮 / 暗。顶栏颜色通过 `setHeaderColor` 设成 `--color-dark`。
- 底部主操作按钮固定在安全区上方，高 48px，全宽。
- 金额、状态等业务规则不变（金额 e4 整分显示、状态文案三语）。

## 8. 页面模板
| 页面 | 结构 |
| --- | --- |
| 首页 | 按 `design/website/homepage-v2/source.html`，见批次卡 #222 |
| 内页（商家、联系） | 深色页头 → 米色首区（eyebrow + `--fs-h1` 标题 + 导语）→ 内容区块（交替底色）→ 页脚 |
| 法律页 | 同内页；正文 `--fs-body`，行宽 `--measure`；草案横幅保留；**只改样式不改文字** |

## 9. 验收
- 视口 320、360、375、390、414、430、600、768、1024、1440、1920px × 中 / 英 / 高棉语：无横向滚动、标题末行不只剩 1–2 个字、文字不被截断。
- 样式里不出现写死的色值和字号（tokens.css 除外）；新增颜色或字号先改本标准。
- Lighthouse 手机 ≥ 80、LCP ≤ 2.5 秒；可访问性检查无对比度、焦点、alt 问题。
