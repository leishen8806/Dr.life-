**版本：** 2026-10-31（旗舰版）　**域名：** `settlecore.org`　**状态：** 设计定稿，进入实现
**原型：** 本目录 `prototype/` 下 5 个画布原型（`Main` 桌面首页、`Mobile` 手机首页、`Merchant` 商家合作与费用、`Legal` 法律文件模板、`Style` 视觉规范）。原型是带内联样式的 HTML 片段，`<x-dc>`、`<helmet>`、`<sc-*>` 是画布工具的标签，实现时只参考其中的结构、文案与样式数值，不照搬这些标签。

依据：《Dr.life+柬埔寨落地方案》第四章（定位、VI、对外用语核验表）、《Dr.life+第一版交付形态与技术架构》第七章（域名与官网）、《Dr.life+第一批商户与定价试探方案》、《Dr.life+Bot资料与高棉语欢迎语》、《Dr.life+用户协议与隐私政策草案(三语)》、`historical/` 下 VI 手册与投资人修订版 PPT。

## 一、定位与目标

- DR.LIFE+ 是面向柬埔寨的新一代综合商业平台：**前期从建材家居切入，长期成为柬埔寨全行业的领头平台**（综合电商、品牌商城、本地生活与数字金融服务）。官网要有平台级企业官网的格局，而不是促销落地页。
- 官网的三个任务：
  1. **建立信任**：说明 `settlecore.org` 就是 DR.LIFE+ 的官方网站，承载隐私政策、用户协议、账号删除说明与联系方式（所有 Bot 的隐私链接指向这里）。
  2. **讲清品牌与愿景**：口号「生活·无限可能 / INFINITE POSSIBILITIES!」，三阶段成长路径，平台生态。
  3. **招商与导流**：本地商家、中国品牌与厂家、战略伙伴三类合作入口；买家导流到 Telegram 商城。
- 主要访问场景：用户在 Telegram 里点开链接，**手机端与桌面端同等重要**。

## 四、首页结构（旗舰版）

1. **首屏**（深石墨 `#131517` 满版）：顶部导航（愿景 / 平台生态 / 一条龙服务 / 商家合作 / 关于我们 + 语言切换 + 「进入商城」）；英文小标 `CAMBODIA · NEXT-GENERATION COMMERCE`；主标题「生活·无限可能」（衬线 132px，手机 60px）；副标 `INFINITE POSSIBILITIES`；一句定位；主按钮「成为合作商家」（香槟金底）、次按钮「了解 DR.LIFE+」；右侧开放圆弧组合图形；底部四个大数字（0% 佣金、$14 仓储起价、10,000 m³、3 语）。
2. **愿景三阶段**：01 建材家居（进行中）/ 02 全品类商城（规划）/ 03 生活与金融服务生态（愿景）。阶段标签必须保留。
3. **平台生态图**：中心 DR.LIFE+，周围六项；线上商城、本地仓配、跨境供应链、支付结算为实色「已开放」，商家服务、生活服务为虚线「规划中」，附图例。
4. **从建材家居开始**：编辑式品类拼图（瓷砖与地板大图 + 卫浴、门窗、家具、涂料）。
5. **一条龙链路**：六步横向链，第 5 步「DR.LIFE+ 销售」金色高亮，下附「以报价单为准」。
6. **与 DR.LIFE+ 一起成长**：本地商家入驻 / 中国品牌与厂家 / 战略与生态伙伴（深色卡）。
7. **页脚**：大字标、口号、高棉语欢迎语、法律链接、版权占位、官方网站声明。

手机端按 `Mobile` 原型：单列、全宽按钮、汉堡菜单、触控目标 ≥44px。

## 五、视觉规范

- **颜色：** 石墨 `#202326`、深石墨 `#131517`（大面积深色区）、暖象牙 `#F4F1EB`（底色）、浅象牙 `#EAE5DB` / `#FBFAF7`（分区底）、香槟金 `#B69A64`（只作强调）、深金 `#8A7247`（象牙底上的金色小字，保证 4.5:1）、浅金 `#D8C08F`（深底上的小字）、拉丝银 `#C7CBCF`（结构线）。
- **字体：** 中文标题 `Noto Serif SC` 600；中文正文 `Noto Sans SC`；英文与数字 `Inter`（大数字用 200 细体）；高棉语 `Noto Sans Khmer`，行高 ≥1.6、不得截断。
- **字号：** 首屏主标 132 / 手机 60；区块标题 56–64 / 手机 30–32；正文 16–17，最小 15；英文小标 13，字距 0.32em。
- **版式：** 内容最大宽 1280，左右 48（手机 20）；区块上下 140（手机 72）；按钮直角、最小高 44（主按钮 60）；金色只用于细线、数字、加号与主按钮。
- **辅助图形：** VI「开放圆弧」：一条完整细银圆 + 一条金色缺口圆弧 + 实心深色圆面。
- **Logo：** 实现期用文字字标 `DR.LIFE+`（加号香槟金）；拿到核准矢量母版后替换。
- **禁止：** 渐变铺底的模板感、emoji、左侧色条卡片、厚重投影、照搬任何其他平台的视觉。

## 六、设计规划边界

### 6.1 本期做（第一版官网）
- 第三节 6 个页面，三语切换框架；中文全文，英文首页与商家页全文，高棉语至少完成导航、首屏、页脚与法律页框架（正文由 Localizer 补齐）。
- 纯静态站点：**Astro** 生成，放 `apps/website`，接入现有 pnpm workspace；构建产物部署到 Cloudflare（部署由董事会执行，不在实现卡内）。
- 法律页正文：第一版从 `Dr.life+用户协议与隐私政策草案(三语).md` 生成并标注「草案，待律师审核」；后续改为读取管理后台「协议与政策」已发布版本（N-07 完成后另开卡）。
- 响应式 1440 / 768 / 390；Lighthouse 性能、可访问性、最佳实践、SEO 均 ≥90；首屏不依赖大图也能完整呈现。
- 基础 SEO：每页 `title` 含 DR.LIFE+、`description`、Open Graph、`hreflang`、站点地图。

### 6.2 本期不做
- 登录、注册、下单、付款、表单提交、任何个人信息收集（官网不处理登录和交易）。
- 埋点与第三方统计、Cookie 横幅（不设置非必要 Cookie；以后要加统计另开卡并先过隐私审查）。
- 投资者关系、融资信息、团队介绍、新闻中心、招聘、合作伙伴 Logo 墙（无签约事实前不放）。
- 任何金融、贷款、分期、保理、典当相关页面或入口。
- 商品列表与价格（商品在 Telegram 商城里，官网只导流）。

### 6.3 合规红线（任何一条违反即不通过审查）
- 禁用词：「24h 仓配无忧」「使命必达」「全柬配送」「一仓入柬、全柬销售」「精装交付与监理」「质量监理」「官方质检验收试点平台」「网商贷」；不得声称持有任何金融或资质牌照。
- 不写「比同行低 X%」，只写「14 美元起」。
- 时效、线路、清关、费用一律「按商品和订单逐项确认，以报价单为准」。
- 金融只出现在愿景第 3 阶段，措辞固定为「金融类服务只与持牌机构合作提供，目前尚未开放」。
- 买家可见页面不出现仓配承运方（RouteFit）名称；不点名其他平台或公司。
- 不编造数据、用户数、客户评价与合作伙伴；缺的事实用 `[方括号占位]`。
- 首屏或页脚必须有官方声明：「settlecore.org 是 DR.LIFE+ 的官方网站，本站不处理登录和付款，不会索要密码或银行卡信息」。

### 6.4 占位清单（实现时保留方括号，等负责人提供）
运营主体公司名称与年份；联系方式与客服时间；法律文件版本号、生效日期与优先语言；品类与仓库实拍照片；核准 Logo 矢量；Bot 用户名 `DrLifePlusBot`、`DrLifeMerchantBot`（待注册确认，集中成常量）；付款通道费口径。

## 七、实现与验收

- **分工：** 设计补全（UIUX）→ 文案与三语（Localizer）→ 实现（前端）→ 非作者前端代码审查 → 董事会复验与部署。
- **验收：** 三个宽度截图；第 6.3 节禁用词全文搜索结果为零；所有链接可点；`/privacy`、`/terms` 固定网址可用；Lighthouse 四项 ≥90；`pnpm -F @drlife/website build` 在 node:22 容器中通过；不新增运行时依赖之外的第三方脚本。
