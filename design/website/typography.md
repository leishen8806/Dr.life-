# 官网字号规范

本规范来自 Issue #177 的负责人确认，适用于官网现有页面及后续页面。

## 字号档位

屏幕宽度从 360px 到 1440px 连续缩放；360px 以下使用最小值，1440px 以上使用最大值。

| 变量 | 用途 | 最小值 | 最大值 | CSS |
| --- | --- | ---: | ---: | --- |
| `--fs-display` | 首屏大标题 | 44px | 132px | `clamp(44px, 14.7px + 8.15vw, 132px)` |
| `--fs-tagline` | 首屏英文副标题 | 14px | 40px | `clamp(14px, 5.3px + 2.41vw, 40px)` |
| `--fs-h2` | 各节标题、法律页 h1 | 26px | 56px | `clamp(26px, 16px + 2.78vw, 56px)` |
| `--fs-h3` | 卡片和步骤标题 | 18px | 24px | `clamp(18px, 16px + 0.56vw, 24px)` |
| `--fs-stat` | 数据栏数字 | 28px | 56px | `clamp(28px, 18.7px + 2.59vw, 56px)` |
| `--fs-lead` | 首屏简介 | 16px | 21px | `clamp(16px, 14.3px + 0.46vw, 21px)` |
| `--fs-body` | 正文、各节说明 | 15px | 17px | `clamp(15px, 14.3px + 0.19vw, 17px)` |
| `--fs-small` | 注释、卡片说明、数据栏标签 | 12px | 14px | `clamp(12px, 11.3px + 0.19vw, 14px)` |
| `--fs-eyebrow` | 英文大写小标题 | 11px | 13px | `clamp(11px, 10.3px + 0.19vw, 13px)` |

除 eyebrow 外，任何文字不得小于 12px。新增样式应引用上述变量，不直接写固定字号。

## 行高与字距

- 标题行高 1.15，正文行高 1.7。
- 高棉语正文行高 1.85，标题行高 1.35；高棉语不加字距。
- 英文副标题和 eyebrow 在手机上使用 `.12em` 字距，900px 以上恢复 `.32em`。

## 换行与间距

- h1、h2、h3 和 eyebrow 使用 `text-wrap: balance`；正文使用 `text-wrap: pretty`。
- 中文标题按语义断行；不得通过缩小字号解决 360px 下的溢出。
- 数字、单位和语言列表不得拆开：`15 美元起`、`15,000 m³`、`0%`、`3+`、`中文 · English · ខ្មែរ`。
- 页面左右边距：520px 以下 20px，521–900px 32px，900px 以上 48px。

## 验收视口

使用 320、360、375、390、414、430、600、768、1024、1440、1920px，分别检查中文、英文和高棉语：标题末尾不得只剩 1–2 个字；不得出现横向滚动条；文字不得被截断。
